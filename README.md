# 🍳 Recipes Rush

**Recipes Rush** is a cooking game developed in **Unity**, where players prepare different recipes by interacting with ingredients and kitchen objects.

The game focuses on simple and interactive cooking mechanics, allowing players to combine ingredients and complete recipes in a fun and fast-paced environment.

---

## 🎮 About the Game

In **Recipes Rush**, the player takes the role of a cook and must prepare recipes using the ingredients available in the kitchen.

The game includes a main menu and a kitchen environment where the player can interact with different cooking objects and ingredients.

The goal is to successfully prepare the required recipes and complete the cooking challenges.

---

## ✨ Features

- 🍅 Interactive cooking ingredients
- 🍝 Recipe preparation
- 🍳 Kitchen environment
- 🥬 Different food ingredients
- 🥣 Interactive kitchen objects
- 🎮 Simple and accessible gameplay
- 🖥️ Main menu
- 🎨 Custom visual design
- 🔄 Object interaction and game logic

---

## 🕹️ Gameplay

The basic gameplay consists of preparing recipes using the available ingredients.

The player interacts with objects in the kitchen and follows the requirements of each recipe.
